# 🎮 Super Mario Party Jamboree
Bienvenue dans Super Mario Party Jamboree ! Cette application React Native vous permet de sélectionner aléatoirement des cartes inspirées de l'univers de Mario Party pour pimenter vos soirées jeux.

## 🚀 Fonctionnalités
-  Sélection aléatoire de cartes parmi une liste prédéfinie.
-  Animations fluides et interface utilisateur attrayante.
-  Musique d'ambiance pour une expérience immersive.

## 🛠️ Technologies utilisées
-  React Native : Framework principal pour le développement mobile.
-  React Navigation : Gestion de la navigation entre les écrans.
-  Zustand : Gestion de l'état global de l'application.
-  Expo : Plateforme facilitant le développement et le déploiement.
-  React Native Reanimated : Gestion des animations complexes.
-  Expo AV : Lecture de fichiers audio pour la musique d'ambiance.

##  📦 Installation
1.  Cloner le dépôt

```
git clone https://github.com/votre-utilisateur/super-mario-party-jamboree.git
cd super-mario-party-jamboree
```
2.  Installer les dépendances

Assurez-vous d'avoir Node.js et Expo CLI installés.

```
npm install -g expo-cli
npm install
```

3.  Lancer l'application
```
expo start
```
Utilisez l'application Expo Go sur votre appareil mobile ou un émulateur pour prévisualiser l'application.
